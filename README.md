# 대본 연습실

연극 대본(PDF·한글 HWP/HWPX·텍스트)을 올리면 막·장을 나누고, 작품·기승전결·인물 관계도·인물 분석을 정리하고,
내 대사를 가려 외우게 돕는 웹앱입니다. 휴대폰 홈 화면에 추가해 앱처럼 쓸 수 있어요.

- AI 분석: 키 없이(ChatGPT·제미나이 앱에 질문 붙여넣기) 또는 제미나이/ChatGPT API 키
- 저장: 이 기기(IndexedDB)에만 저장. 다른 기기로는 백업 파일로 옮겨요.
- 서버 없음: 대본은 분석할 때 고른 AI 회사로만 보내져요.

`tools/make-icons.mjs` 로 아이콘을 다시 만들 수 있어요. 배포할 때는 `sw.js` 의 `CACHE` 버전을 올리세요.
